# Hola, soy Kevin Quispe 👋

**Desarrollador de software · Automatización e IA aplicada**  
📍 Lima, Perú

Desarrollo aplicaciones web, de escritorio para Windows y móviles para Android e iOS. Mi trabajo se centra en digitalizar procesos, automatizar tareas y conectar la información dentro de las áreas y entre equipos para mejorar la eficiencia operativa.

Integro modelos de inteligencia artificial mediante APIs y soluciones **RAG (generación aumentada por recuperación)** con Python y pgvector. Mi desarrollo profesional está orientado a **AI Engineering**, con énfasis en incorporar IA a aplicaciones que resuelvan necesidades de negocio.

## Experiencia destacada

- **Integración de procesos empresariales:** desarrollo de sistemas para conectar producción y compras, y bots de Telegram para gestionar inventarios y enviar notificaciones diarias.
- **Aplicaciones para campo y oficina:** soluciones para Android y Windows que conectan la información del personal de campo con la oficina central y apoyan procesos de operaciones, logística, recursos humanos e ingeniería.
- **Gestión documental e IA para el sector legal:** aplicación Windows para organizar expedientes PDF, buscar palabras clave y localizar documentos, fojas y páginas. Integración de RAG con Python y pgvector para responder consultas a partir de la información de los expedientes.
- **Datos y automatización:** análisis de datos para apoyar decisiones, extracción automatizada con web scraping y experiencia impartiendo capacitaciones de automatización con Python.
